# Lístek Internetové bankovnictví

Responzivní prototyp internetového bankovnictví postavený na Next.js 16, Reactu 19 a TypeScriptu. Vizuální směr vychází z jednoduchosti moderních českých bank, používá ale vlastní značku a design.

## Funkce

- přehled běžného a spořicího účtu
- skrytí citlivých zůstatků
- filtrování historie transakcí
- formulář nové platby s potvrzovacím stavem
- přehled výdajů a finanční tip
- responzivní mobilní navigace

Data jsou pouze ukázková a platby se nikam neodesílají.

## Spuštění

```bash
npm install
npm run dev
```

Aplikace bude dostupná na [http://localhost:3000](http://localhost:3000).

## Kontrola

```bash
npm run lint
npm run build
```
